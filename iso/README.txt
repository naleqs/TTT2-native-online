Put your own Tekken Tag Tournament 2 (Xbox 360) disc image here, then run Setup.bat.

  - a .iso file (a 1:1 dump of your disc), or
  - a folder with the extracted disc (it must contain Default.xex)

If exactly one image is found here, setup uses it without asking, so the whole
first-time setup can be done without a mouse.

Nothing in this folder is ever uploaded: .gitignore excludes it.
